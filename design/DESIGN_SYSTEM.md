# DOGS 디자인 방향 · 디자인 시스템 (v0.2)

홈 시안 v0.1: [home-draft.html](home-draft.html) · 토큰: [tokens.json](tokens.json) (primitive → semantic light/dark → component)

## v0.2 변경 사항
- 가운뎃점으로 이어 붙인 메타 문구 제거 → 자연어 문장 ("콩이에게 사료 80g", "콩이, 보리와 40분")
- 홈 목록 재구성: `지금 할 일` 카드 / `남은 일` / `받은 요청` / `완료`(누가 언제 했는지 로그: "민지가 아침 급여 완료  07:42") — v0.1의 저녁 급여 중복 제거
- 하루 레일: 시간이 붙은 일정(07:30, 08:00)은 캡슐 하나로 합쳐 개수 표시
- 사진 플레이스홀더 그라데이션 제거 → 단색 톤
- 대비 보정: `ink3` #8A938E(2.9:1) → **#687270**(4.6:1), `amber` #A85F17(4.2:1) → **#965210**(5.1:1)
- 다크 모드 semantic 토큰 정의 + 다크 홈 프레임
- 버튼 상태(기본/눌림/처리 중/비활성), 체크 상태(예정/지연/완료), 칩 상태 정의

## 1. 프로젝트 분석

- **목적**: 가족·친구가 그룹 단위로 반려견을 함께 돌볼 때 "밥 줬어?" 확인 반복, 중복 급여, 누락을 없앤다.
- **핵심 사용자**: 그룹장(일정 관리자, 보통 보호자 1명) / 멤버(체크·제안·요청). 하루에 여러 번, 짧게(5~10초) 앱을 연다.
- **홈의 핵심 질문**: "지금 해야 할 일이 뭐고, 이미 누가 했나?"

### 화면 목록과 관계

```
[로그인/회원가입] → [그룹 없음: 그룹 만들기 | 초대 코드 입력] → [홈]
홈 ─┬─ 알림함(상단 벨)
    ├─ 그룹 전환(상단 그룹명)
    ├─ 할 일 탭 ─ ToDo 상세 ─ (그룹장) 생성·수정 / (멤버) 변경 제안 작성
    ├─ 사진첩 탭 ─ 사진 상세 ─ 업로드(반려견 태그)
    └─ 그룹 탭 ─ 반려견 프로필(등록·수정) / 멤버·초대 코드 / 그룹장 위임·탈퇴 / 받은 제안 승인·거절
```

### 핵심 흐름
1. **완료 체크**: 홈 → "지금 할 일" 카드 → 완료했어요 → 즉시 "민지 17:52" 기록 표시 (다른 멤버에게 실시간 반영)
2. **요청**: 홈 받은 요청 → 맡을게요/어려워요 → 요청자에게 알림
3. **변경 제안**: 할 일 상세 → 변경 제안 → 그룹장 알림 → 승인/거절 → 결과 알림

### 가정 (확정 아님)
- 홈 = 현재 선택된 그룹의 **오늘** 화면. 여러 그룹 소속 가능 → 상단 그룹명으로 전환.
- 하단 탭 4개: 홈 / 할 일 / 사진첩 / 그룹. 알림은 탭이 아니라 상단 벨(빈도 낮은 확인 행위).
- "지연" 기준: 예정 시각이 지났는데 미완료. 알림 시점·유예 시간은 미정.
- ToDo 완료 취소(실수 체크) 가능 여부 미정 → 시안에선 고려 안 함.
- 건강 상식 팁은 확장 기능 → 홈 하단, 낮은 위계로 배치(없어도 레이아웃 유지).
- 사진은 실제 이미지 대신 톤 플레이스홀더.

## 2. 콘셉트 검토

| 콘셉트 | 설명 | 판단 |
|---|---|---|
| A. 소프트 파스텔·캐릭터 | 둥근 일러스트, 파스텔, 귀여운 반려견 앱 정석 | 흔함. 가족 공용 "업무 확인" 도구엔 정보 밀도·신뢰감 약함 |
| B. 헬스케어 클리니컬 | 쿨 그레이 + 블루, 대시보드형 | 신뢰는 있으나 차갑고 반려견과 정서 거리 큼 |
| **C. 차분한 생활 도구 (선정)** | 세이지 기운 오프화이트, 짙은 그린 블랙 잉크, 에버그린 단일 포인트, 하루 타임라인이 시그니처 | 아래 근거 |

**선정 근거**: 이 앱의 본질은 "귀여움"이 아니라 **기록의 신뢰** — 누가, 언제. 완료=에버그린, 지연·요청=앰버 두 의미색만 써서 상태가 색으로 즉시 읽힌다. 반려견의 따뜻함은 견별 아바타 톤(콩이 베이지, 보리 블루그레이)과 사진에 맡기고 UI 자체는 절제.

**시그니처 요소**: 홈 상단 **하루 레일**(6시~24시). 완료(그린 체크), 지연(앰버 링), 예정(빈 링), 지금 위치가 한 줄에 보인다. 대시보드식 큰 숫자/원형 진행률 대신 "하루가 얼마나 채워졌나"를 시간축으로 보여 누락이 공간적으로 드러남.

### 간격 (4dp 그리드)
`4 · 8 · 12 · 16 · 20 · 24 · 28 · 36` — 화면 좌우 여백 20dp, 섹션 간 36dp, 리스트 행 최소 68dp.

### 모서리
`sm 8`(작은 요소) · `md 12`(사진) · `lg 20`(카드) · `full`(버튼·칩·배지). 위계별로 다르게 — 전부 같은 반경 금지.

### 그림자
없음이 기본. 카드는 `line2` 1dp 테두리로 구분. 하단 탭만 상단 1dp 선 + 반투명.

### 아이콘
24dp 라인, stroke 1.75 (선택 시 2.0), 둥근 끝. Material Symbols Rounded(weight 300~400)로 대체 가능.

## 4. 컴포넌트 (홈에서 정의된 것)
- **TopBar 64dp**: 그룹 전환 버튼(그룹명 + 인원 + ▾) / 알림 아이콘 버튼 48dp + 미확인 점
- **DogFilterChip 40dp**: 전체 / 견별(아바타 32dp + 이름). 선택=ink 채움
- **DayRail**: 6~24시 축, 상태 3종(done / late / upcoming) + 지금 마커
- **NextTaskCard**: 상태 라벨(앰버) + 제목 + 메타 + 견 아바타 + 주 버튼(48dp, 전체폭) + 체크 현황
- **TaskRow 68dp**: 시간 / 제목+메타 / 트레일링(완료 배지 "민지 07:42" 또는 체크 버튼 48dp 터치영역)
- **RequestCard**: 앰버 틴트, 보낸 사람·내용·시간 + 맡을게요(주)/어려워요(보조)
- **PhotoTile 112×140**, **TipRow**, **NavigationBar** (M3, 아이템 4, 활성 인디케이터 56×32)

## 5. 홈 정보 위계 (위→아래)
1. 그룹 컨텍스트 + 알림 (어디 그룹인지)
2. 견 필터 (누구 기준인지)
3. 오늘 진행 문장 + 하루 레일 (전체 상황 3초 파악)
4. **지금 할 일** — 화면 내 유일한 큰 주 버튼
5. 오늘 할 일 전체 (누가·언제 했는지 기록)
6. 받은 요청 (있을 때만 노출)
7. 최근 사진, 건강 상식 (정서·확장, 낮은 위계)

상태 변형(다음 단계에서 제작): 모두 완료 / 할 일 없음(그룹장: "할 일 만들기", 멤버: 안내) / 지연 없음 / 요청 없음 / 반려견 미등록 / 로딩 스켈레톤.

## 6. 모션 (절제)
- 완료 체크: 원 → 그린 채움 + 체크 그리기 200ms, 행이 배지로 교체 150ms, 레일 해당 눈금 동기 채움. 햅틱 `CONFIRM`.
- 지금 할 일 카드: 완료 후 다음 항목으로 crossfade 250ms.
- 그 외 진입 애니메이션 없음. `reduce motion` 시 즉시 전환.

## 7. Jetpack Compose 구현 시 주의
- **Edge-to-edge**: `enableEdgeToEdge()` + `Scaffold` 의 `WindowInsets.systemBars` 처리. 상태바 아이콘 어둡게(밝은 paper 배경).
- **터치 영역**: 체크 원은 26dp 시각 크기지만 `Modifier.minimumInteractiveComponentSize()`로 48dp 보장. 섹션 "전체 보기" 링크도 48dp 높이.
- **NavigationBar**: M3 `NavigationBar` 80dp, `indicatorColor = primaryContainer`. 탭 4개 유지.
- **색**: 위 표대로 `lightColorScheme(...)` 커스텀 정의, 컴포넌트에서 hex 직접 사용 금지. 의미색(완료/지연)은 `ColorScheme` 확장 대신 별도 `DogsColors` `CompositionLocal` 권장.
- **타이포**: Pretendard를 `res/font`에 포함(가변 대신 400/500/600/700 static), `Typography(...)` 재정의. 숫자 정렬은 `fontFeatureSettings = "tnum"`.
- **폰트 스케일**: 200%까지 깨지지 않게 — 헤드라인 `\n` 하드 줄바꿈 대신 자연 줄바꿈, TaskRow는 높이 고정 금지(`heightIn(min = 68.dp)`).
- **DayRail**: `Canvas`로 그리고 `semantics { contentDescription = "오늘 6개 중 4개 완료, 저녁 급여 지연" }`. 색만으로 상태 전달 금지 → 지연은 링 + 텍스트 병행(이미 리스트에 "20분 지남").
- **반응형**: 폭 600dp 이상(폴더블/태블릿)은 2열 — 좌: 헤드라인·레일·지금 할 일, 우: 할 일 리스트. `WindowSizeClass` 사용.
- **실시간성**: Firestore 리스너로 완료 상태 반영 시 낙관적 업데이트 + 충돌(동시 체크) 시 먼저 체크한 사람 표시하고 스낵바 "민지님이 이미 완료했어요".
- **아바타 이니셜**: 사진 없을 때 이름 첫 글자 + 견별 고정 톤.

## 8. 핵심 화면 v0.2 (로그인 · 할 일 · 사진첩 · 그룹)

Figma 프레임: Login `55:2`, Todo `56:2`, Photos `57:2`, Group `58:2`, Group 전체 `59:2` · 디자인 시스템 v0.2 `60:2`(기초), `61:2`(컴포넌트) · 신규 컴포넌트 토큰은 [tokens.json](tokens.json) `component` 참고.

### 로그인
- 앱의 상징인 하루 레일을 브랜드 마크로 다시 써서 홈과 첫인상을 잇는다.
- 헤드라인은 기능이 아니라 해결하는 문제로: "밥 줬는지, 산책 갔는지 이제 묻지 않아도 돼요".
- 라벨은 필드 위에 항상 보이게(플레이스홀더만 쓰지 않음), 비밀번호 보기 토글 48dp, 포커스 상태는 primary 2dp 테두리.
- 가정: 이메일 로그인 + Google 로그인(Firebase Auth). 회원가입·비밀번호 찾기 화면은 다음 단계.

### 할 일
- 주간 날짜 스트립: 선택 날짜는 inverse 채움, 아래 점 = 그날 모두 완료(primary) / 놓친 일 있음(attention).
- 그룹장에게만 변경 제안 배너 노출: "민지가 저녁 산책을 20:00으로 옮기자고 했어요" + 승인/거절.
- 하루를 아침(6~11시)·낮(11~17시)·저녁(17시~)으로 묶어 실제 시간 순서를 유지. 행마다 반려견 아바타 + 반복 규칙.
- `할 일 추가` 확장 FAB는 그룹장만. 멤버 화면에서는 FAB 대신 할 일 상세의 "변경 제안"으로 연결(가정).

### 사진첩
- 카드 없이 날짜별 3열 그리드(간격 4, 타일 반경 8). 날짜 머리글 오른쪽에 "민지가 4장 올렸어요"처럼 누가 올렸는지.
- 여러 장 묶음은 우상단 겹침 표시. 반려견 필터 칩은 홈과 동일 컴포넌트.
- `사진 올리기` FAB는 모든 멤버.

### 그룹
- 순서: 그룹 머리글 → 반려견(52dp 아바타, "말티즈, 4살, 3.2kg") → 멤버(그룹장 배지, 이번 주 완료 횟수) → 초대 코드 → 그룹 나가기.
- 초대 코드는 그룹장에게만 노출(가정), 7일마다 갱신(가정). 코드 복사 / 공유.
- 그룹 나가기는 error 색 텍스트 버튼, 실행 전 확인 다이얼로그 필수. 그룹장은 위임 후에만 나갈 수 있음(README 권한 정책).
- 설정(톱니)에는 그룹 이름 변경, 그룹장 위임을 둔다(다음 단계).

### 다음 단계 후보
회원가입, 그룹 만들기/초대 코드 입력(그룹 없음 상태), 할 일 생성·수정(반복 규칙 선택), 할 일 상세 + 변경 제안 작성, 사진 상세(반려견 태그), 반려견 프로필 편집, 알림함, 각 화면 다크 모드와 빈 상태.

### 화면 결정 메모
- **문구 일관성**: 버튼과 결과 문구가 같은 동사 — `할 일 저장`, `제안 보내기`, `아빠에게 요청 보내기`, `엄마에게 위임하기`, `보리 등록하기`, `4장 올리기`. 버튼에 대상(누구·몇 장)을 넣어 누르기 전에 결과를 알게 함.
- **오류**: 필드 아래에 무엇이 틀렸는지 구체적으로("비밀번호가 서로 달라요"), 라벨도 error 색. 필수값이 맞기 전에는 하단 버튼 비활성.
- **빈 상태**: 하루 레일 모티프(빈 눈금)를 그룹 시작·홈 빈 상태에 재사용. 다음 행동 버튼 + 시작 체크리스트.
- **권한 반영**: 할 일 상세의 `변경 제안`은 멤버용(그룹장에게는 `수정`으로 대체), 그룹 설정·위임·초대 코드 재생성은 그룹장 전용, 그룹장은 위임 전 나가기 불가.
- **사진 자세히 보기**는 사진에 집중하도록 유일한 어두운 화면. 태그 추가는 모든 멤버, 삭제는 올린 사람만(가정, ⋮ 메뉴 안).
- **AI 도우미**(확장): 그룹 기록 요약 답변 + 추천 질문 + 수의사 상담 안내. 반짝이 아이콘 같은 AI 상투 표현은 쓰지 않음.

### 가정 (확정 필요)
- 비밀번호 규칙: 8자 이상, 숫자, 특수문자. 재설정 링크 유효 30분.
- 그룹 만들기는 2단계(이름 → 첫 반려견), 초대 코드 6자리·대소문자 무시·7일 갱신.
- 요청은 오늘 할 일에서 고르거나 직접 입력.
- 알림 설정은 4종(전체, 할 일 시간, 요청과 제안, 새 사진). 테마는 시스템/라이트/다크.
- 회원 탈퇴 시 데이터 처리 정책 미정 → 별도 확인 다이얼로그 필요.
